# Changelog

## 0.1.0

The first release: `extractRawText` and `extractRawTextSync`, returning the same text as
mammoth 1.13.0's `extractRawText` on every file of a 1,610-document public corpus and on
20,000 generated documents, and failing on the same files; and `declaredXmlBytes`, an
upper bound on the XML a read parses, read from the zip directory. Node 20+, browsers,
workers and edge runtimes, with the WebAssembly embedded. See the README for the numbers.
